# superstore-sales-business-analytics
Sales and Business Performance Analytics using Excel, PostgreSQL and Power BI.
Superstore Sales & Business Performance Analytics

Project Overview

An end-to-end data analytics project that analyzes retail sales data to identify business trends, evaluate profitability, and generate actionable insights.

Dataset

- Dataset: Sample Superstore
- Records: 9,994
- Format: CSV

Tools & Technologies

- Microsoft Excel – Data analysis and pivot tables
- PostgreSQL – Data storage and SQL analysis
- Power BI – Interactive dashboard and visualization

Project Workflow

1. Data exploration and preparation
2. Excel analysis using Pivot Tables and charts
3. SQL analysis using PostgreSQL
4. Interactive dashboard development using Power BI

Key Performance Indicators

- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Average Sales: 229.86
- Profit Margin: 12.47%

Business Insights

- West region generated the highest sales and profit.
- South region recorded the lowest sales.
- Regional and product-category performance were compared.
- Monthly sales trends were analyzed.
- Top 10 products were identified based on profit.

Repository Structure

- "Dataset/" – Original dataset
- "Excel/" – Excel analysis
- "SQL/" – PostgreSQL queries
- "PowerBI/" – Power BI dashboard

Project Status

Completed – Excel, PostgreSQL and Power BI analysis.
